# Автоматизация бэкапа (systemd/cron/logrotate)

Конфигурации для интеграции системы бэкапа с операционной системой: systemd service+timer (современный подход) и cron (альтернативный). Плюс logrotate для ротации логов.

## Основные характеристики

### systemd: familybudget-backup.service

Запускает `backup.sh` как oneshot-сервис:

```
WorkingDirectory: /opt/familybudget
ExecStart: /opt/familybudget/scripts/backup.sh
EnvironmentFile: /opt/familybudget/.env
TimeoutStartSec: 1h
CPUQuota: 50%
MemoryLimit: 512M
```

**Настройки безопасности:** `PrivateTmp=yes`, `NoNewPrivileges=yes`.

**Логи:**
- stdout → `/var/log/familybudget/backup.log`
- stderr → `/var/log/familybudget/backup_error.log`

### systemd: familybudget-backup.timer

Timer-unit для ежедневного запуска сервиса бэкапа:

```
OnCalendar: *-*-* 02:00:00   # Ежедневно в 02:00
OnBootSec: 10min              # Запуск через 10 мин после загрузки (если был пропущен)
Persistent: true              # Запустить пропущенные таймеры после reboot
AccuracySec: 15min
RandomizedDelaySec: 5min      # Распределение нагрузки
```

### cron: familybudget-backup.cron

Альтернатива systemd-timer:

```bash
# Установка
sudo cp scripts/cron/familybudget-backup.cron /etc/cron.d/familybudget-backup
sudo chmod 644 /etc/cron.d/familybudget-backup

# Задание
0 2 * * * root cd /opt/familybudget && set -a && source .env && set +a && ./scripts/backup.sh >> /var/log/familybudget/cron.log 2>&1
```

**Логи:** `/var/log/familybudget/cron.log`, `/opt/familybudget/backups/logs/backup_YYYYMMDD.log`

### logrotate: familybudget

Конфигурация ротации логов (устанавливается в `/etc/logrotate.d/familybudget`):

| Путь | Ротация | Хранение |
|------|---------|---------|
| `/var/log/familybudget/*.log` | daily | 30 дней |
| `/opt/familybudget/backups/logs/*.log` | daily | 30 дней |
| `/var/log/familybudget/cron.log` | weekly | 12 недель |

**Параметры:** `compress`, `delaycompress`, `dateext`, `missingok`, `notifempty`.

### Установка (краткая)

```bash
# systemd (рекомендуется)
sudo cp scripts/systemd/familybudget-backup.service /etc/systemd/system/
sudo cp scripts/systemd/familybudget-backup.timer /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now familybudget-backup.timer

# logrotate
sudo cp scripts/logrotate/familybudget /etc/logrotate.d/familybudget
sudo chmod 644 /etc/logrotate.d/familybudget
```
