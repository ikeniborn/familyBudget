# Утилиты и сервисные скрипты

Набор вспомогательных bash/python скриптов для разовых операций: генерация ключей, создание admin-пользователя, очистка БД, генерация PWA-иконок, валидация кода.

## Основные характеристики

### generate_vapid_keys.sh — VAPID-ключи для Web Push

Генерирует VAPID-ключи для Web Push уведомлений. Ключи генерируются **один раз на сервер** и используются всеми пользователями.

```bash
./scripts/generate_vapid_keys.sh              # Генерация и вывод
./scripts/generate_vapid_keys.sh --update-env # Генерация + запись в .env
```

### create_admin_user.py — создание admin-пользователя

Python-скрипт для создания admin-пользователя из переменных окружения. Admin входит **без требования 2FA** (security exception для аварийного доступа).

**Переменные окружения:**
```
ADMIN_EMAIL         # Email адрес (необязательно)
ADMIN_PASSWORD      # Пароль в открытом виде (будет захеширован Argon2)
ADMIN_TELEGRAM_ID   # Telegram ID (необязательно, для привязки)
DATABASE_URL        # PostgreSQL строка подключения (обязательно)
```

### dev_db_cleanup.py — очистка БД для разработки

Python-скрипт для очистки тестовых данных в базе данных разработчика.

### generate_pwa_icons.sh и fix_vapid_icons.sh

- `generate_pwa_icons.sh` — генерация набора иконок PWA из исходного изображения
- `fix_vapid_icons.sh` — исправление проблем с иконками VAPID

### Скрипты диагностики

- `diagnose_npm_issue.sh` / `fix_npm_issue.sh` — диагностика и исправление проблем с npm
- `show_import_errors.sh` / `check_import_setup.sh` — анализ ошибок импортов ES-модулей

### scripts/validation/ — валидационные скрипты

Автоматическая проверка качества кода. Конвенция именования: `check-*.sh`.

**check-headers.sh** — проверяет стандартизацию заголовков в шаблонах:
- Все H1/H2/H3 имеют responsive-классы (`sm:`)
- Нет inline CSS в template-файлах
- Модальные окна используют H2 (семантическая корректность)

**Коды завершения:** `0` — все проверки пройдены, `1` — найдены нарушения.

**Интеграция:**
- Запуск вручную после изменений шаблонов
- Подключение в pre-commit hooks
- Валидация в CI/CD pipeline
