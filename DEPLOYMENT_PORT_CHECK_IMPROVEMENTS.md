# Улучшение проверки портов в deploy.sh

## Проблема

При повторном деплое скрипт `deploy.sh` обнаруживал, что порты 80/443 заняты процессом nginx (из предыдущего деплоя) и предлагал остановить процесс, хотя это был наш собственный docker контейнер. Это было избыточно, так как `docker compose down` остановит контейнер автоматически позже в процессе деплоя.

## Решение

Добавлена интеллектуальная проверка: если порт занят нашим собственным docker-compose сервисом, скрипт продолжает деплой без лишних предупреждений.

## Изменения в коде

### 1. Новая функция `is_our_docker_container()` (строки 1766-1794)

```bash
is_our_docker_container() {
    local port=$1

    # Проверяет запущенные контейнеры из нашего docker-compose
    # Для каждого контейнера проверяет публикуемые порты
    # Возвращает 0 (success) если порт используется нашим контейнером
}
```

**Логика:**
- Получает список запущенных контейнеров через `docker compose ps`
- Проверяет каждый контейнер на публикацию указанного порта
- Возвращает 0 если это наш контейнер, 1 если нет

### 2. Модификация `check_port_available()` (строки 1823-1827)

Добавлена проверка после вывода информации о занятом порте, но перед проверкой на certbot:

```bash
# Check if this is our own docker-compose service
if is_our_docker_container "$port"; then
    info "Port $port is used by our docker-compose service - will be restarted during deployment"
    return 0
fi
```

## Новое поведение

### Сценарий 1: Повторный деплой (порт занят нашим nginx)

**Было:**
```
[WARNING] Port 80 is already in use!
Process using port 80:
dockerd 403488 root ...

Опции:
  [1] Остановить процесс и продолжить
  [2] Изменить порт в .env файле
  [3] Отменить деплой
```

**Стало:**
```
[WARNING] Port 80 is already in use!
Process using port 80:
dockerd 403488 root ...

[INFO] Port 80 is used by our docker-compose service - will be restarted during deployment
```
*Автоматически продолжает деплой без меню*

### Сценарий 2: Конфликт с другим процессом (Apache, host nginx, и т.д.)

**Поведение не изменилось** - показывается меню с опциями:
