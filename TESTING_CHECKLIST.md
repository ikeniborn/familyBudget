## Тест 7: Backend API проверка

### Прямой запрос к API:
```bash
# 1. Создать категорию
curl -X POST http://localhost:8000/api/v1/admin/articles \
  -H "Content-Type: application/json" \
  -d '{"name":"APITest","type":"expense","parent_id":null}'

# 2. Получить ID созданной категории из ответа

# 3. Изменить тип
curl -X PUT http://localhost:8000/api/v1/admin/articles/{ID} \
  -H "Content-Type: application/json" \
  -d '{"type":"income"}'
```

### Ожидаемый результат:
- ✅ PUT запрос возвращает 200 OK
- ✅ Response содержит обновленную категорию с type="income"
- ✅ new_article.id != old_article.id (SCD Type 2)

## Тест 8: БД проверка (SCD Type 2)

### SQL запросы для проверки:
```sql
-- Проверить что создана новая версия
SELECT id, name, type, is_current, valid_from, valid_to
FROM t_d_article
WHERE name = 'TestCategory'
ORDER BY valid_from DESC;

-- Должно быть 2 записи:
-- 1) is_current=false, type=expense, valid_to=<now>
-- 2) is_current=true, type=income, valid_from=<now>, valid_to=9999-12-31
```

### Ожидаемый результат:
- ✅ Старая версия: `is_current=false`, `valid_to` установлен
- ✅ Новая версия: `is_current=true`, `valid_to=9999-12-31`
- ✅ Оба записи имеют разные `id`
