# Руководство по миграции на новый интерфейс

## Обзор

Мы рады представить новую версию интерфейса Family Budget, построенную на современном стеке React + TypeScript. Новый интерфейс предлагает улучшенную производительность, современный дизайн и расширенные возможности.

## Что нового?

### 🚀 Улучшения производительности
- **Быстрая загрузка** - страницы загружаются в 3 раза быстрее
- **Мгновенные переходы** - переключение между разделами без перезагрузки
- **Оптимизированные графики** - плавная отрисовка и интерактивность

### 🎨 Новый дизайн
- **Современный интерфейс** - чистый и интуитивный дизайн
- **Адаптивность** - отличная работа на всех устройствах
- **Темная тема** (скоро) - комфортная работа в любое время

### ⚡ Новые возможности
- **Управление продуктами** - новый раздел для справочника продуктов
- **Импорт данных** - загрузка из Excel, CSV и Google Sheets
- **Расширенные фильтры** - более гибкая настройка отчетов

## Как получить доступ?

### Этап 1: Тестовая группа
Если вы в тестовой группе, новый интерфейс уже доступен для вас автоматически.

### Этап 2: Постепенный запуск
Новый интерфейс будет доступен для всех пользователей поэтапно:
- **Неделя 1-2**: 25% пользователей
- **Неделя 3-4**: 50% пользователей
- **Неделя 5-6**: 100% пользователей

### Переключение между версиями
В переходный период вы можете переключаться между версиями:
1. В правом верхнем углу найдите меню пользователя
2. Выберите "Настройки"
3. Переключите "Использовать новый интерфейс"

## Основные изменения

### Навигация
- **Старый**: Боковая панель с вкладками
- **Новый**: Фиксированное боковое меню с иконками

### Формы ввода
- **Старый**: Последовательные поля ввода
- **Новый**: Группированные поля с валидацией в реальном времени

### Таблицы
- **Старый**: Базовые таблицы с пагинацией
- **Новый**: Интерактивные таблицы с сортировкой и фильтрацией

### Графики
- **Старый**: Статичные графики Plotly
- **Новый**: Интерактивные графики Recharts с анимацией

## Часто задаваемые вопросы

### Сохранятся ли мои данные?
Да, все ваши данные полностью сохранятся. Изменился только интерфейс.

### Могу ли я вернуться к старой версии?
Да, в переходный период вы можете переключаться между версиями.

### Что делать, если что-то не работает?
1. Попробуйте обновить страницу (F5)
2. Очистите кеш браузера
3. Обратитесь в поддержку через меню "Помощь"

### Будет ли обучение?
Да, мы подготовили:
- Видео-туториалы (доступны в разделе "Помощь")
- Интерактивные подсказки при первом входе
- Эта документация
