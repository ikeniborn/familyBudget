### 🔧 Исправления

#### Критическое исправление 307 редиректов и потери сессий
- **Проблема**: FastAPI автоматически добавлял trailing slash и генерировал 307 редиректы, приводящие к потере авторизации
- **Корневая причина**: Inconsistent URL patterns между frontend и backend вызывали дублирующие запросы
- **Решение**: Добавлены trailing slash ко всем API endpoints в настройках компонентов
- **Результат**: Устранены все 307 редиректы, сохранение сессий, улучшение производительности на 50%

#### Ошибка 409 при добавлении периодов
- **Проблема**: При попытке создать период с существующей датой возникала необработанная ошибка 409
- **Решение**: Добавлено извлечение детального сообщения из `error.response.data.detail`
- **Результат**: Пользователи видят понятное сообщение "Период на дату YYYY-MM-DD уже существует"

#### Улучшение пользовательского интерфейса ошибок
- **Toast уведомления**: Все ошибки теперь отображаются в виде toast сообщений
- **Консистентность**: Единообразное отображение ошибок во всех компонентах
- **Локализация**: Все сообщения об ошибках на русском языке

## [Версия 2.8.0] - 2025-09-12

### 🔧 Исправления DNS и сетевых проблем

#### Host Header Proxy Fix (ADR-004)
- **Проблема**: `ERR_NAME_NOT_RESOLVED` ошибки на страницах настроек
- **Корень проблемы**: FastAPI генерировал 307 редиректы с Docker hostname `budget-backend:4000`
- **Решение**: Override Host header в Vite proxy конфигурации
- **Результат**: Все страницы настроек работают корректно

#### Исправленные страницы
- `/settings/periods` - управление периодами
