# Инструкция по созданию эффективных промтов для Claude

## Основные принципы

### 1. Будьте ясными и прямыми
- Относитесь к Claude как к "блестящему, но очень новому сотруднику с амнезией"
- Предоставляйте контекст: для чего будет использоваться результат, кто аудитория
- Будьте конкретными в требованиях
- Золотое правило: покажите промт коллеге - если ему непонятно, Claude тоже будет непонятно

### 2. Используйте XML-теги для структурирования
```xml
<context>Контекст задачи</context>
<instructions>Четкие инструкции</instructions>
<examples>Примеры желаемого результата</examples>
<output>Формат вывода</output>
```

### 3. Применяйте Chain of Thought (пошаговое мышление)
- Добавляйте "Думай пошагово" для сложных задач
- Используйте теги `<thinking>` и `<answer>` для структурированного вывода
- Полезно для: математики, анализа, принятия решений с множеством факторов

### 4. Используйте примеры (multishot prompting)
- Показывайте несколько примеров желаемого поведения
- Структурируйте примеры однообразно
- Помогает Claude понять паттерны и ожидания

### 5. Оптимизация для длинного контекста
- Размещайте длинные документы в начале промта
- Используйте XML-теги для обертки документов
- Добавляйте метаданные к документам
- Просите сначала процитировать релевантные части

### 6. Предзаполнение ответов (prefilling)
- Начните ответ Claude с желаемого формата
- Например, префилл "{" для JSON-вывода
- Помогает пропустить преамбулы и следовать формату

## Порядок применения техник

1. Сначала сделайте промт ясным и прямым
2. Добавьте структуру через XML-теги
3. Включите примеры для сложных паттернов
4. Добавьте Chain of Thought для аналитических задач
5. Оптимизируйте размещение длинного контекста
6. Используйте предзаполнение для контроля формата

## Чек-лист качества промта

- [ ] Четко определена цель и контекст
- [ ] Указана целевая аудитория результата
- [ ] Используются XML-теги для структуры
- [ ] Предоставлены примеры (если нужно)
- [ ] Добавлено пошаговое мышление (если нужно)
- [ ] Длинные документы размещены вверху
- [ ] Определен формат вывода
- [ ] Промт проверен на ясность коллегой
