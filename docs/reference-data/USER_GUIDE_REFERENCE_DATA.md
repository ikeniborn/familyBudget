## Введение

Система управления справочными данными Family Budget позволяет настраивать и управлять основными справочниками, используемыми для учета семейного бюджета. Все справочники изолированы по пользователям, что обеспечивает конфиденциальность данных.

### Основные возможности

- **CRUD операции** - создание, просмотр, редактирование и удаление записей
- **Иерархические структуры** - поддержка вложенности для ЦФО и номенклатур
- **Массовые операции** - импорт/экспорт данных, групповые обновления
- **Версионирование** - отслеживание всех изменений с возможностью отката
- **Поиск и фильтрация** - быстрый поиск по всем справочникам
- **Валидация данных** - проверка корректности на всех уровнях

## Начало работы

### Доступ к справочникам

1. Войдите в систему через Telegram авторизацию
2. Перейдите в раздел "Настройки" в главном меню
3. Выберите вкладку "Справочники"

### Интерфейс

Интерфейс справочников состоит из:

- **Панель вкладок** - переключение между типами справочников
- **Панель инструментов** - кнопки действий и поиск
- **Таблица данных** - отображение записей справочника
- **Строка состояния** - информация о количестве записей

## Управление периодами

Периоды определяют временные интервалы для планирования и учета бюджета.

### Создание периода

1. Перейдите на вкладку "Периоды"
2. Нажмите кнопку "Добавить период"
3. Заполните форму:
   - **Название** - например, "Январь 2024"
   - **Год** - числовое значение года
   - **Месяц** - число от 1 до 12
4. Нажмите "Сохранить"

### Особенности периодов

- Система автоматически проверяет уникальность комбинации год/месяц
- Нельзя создать два периода с одинаковыми датами
- Периоды автоматически сортируются по дате

### Активация/деактивация периодов

- Используйте переключатель в строке периода
- Неактивные периоды не отображаются в выпадающих списках
- Данные неактивных периодов сохраняются

## Управление финансовыми центрами (ЦФО)

ЦФО представляют организационную структуру для группировки затрат.

### Создание ЦФО

1. Перейдите на вкладку "Финансовые центры"
2. Нажмите "Добавить ЦФО"
3. Заполните:
   - **Название** - наименование центра
   - **Описание** - подробное описание (опционально)
   - **Родительский ЦФО** - для создания иерархии
4. Сохраните изменения

### Работа с иерархией

- Используйте кнопки [+]/[-] для разворачивания/сворачивания ветвей
- Перетаскивайте элементы для изменения структуры
- Система предотвращает циклические зависимости

### Просмотр подчиненных элементов

- Щелкните на ЦФО для просмотра связанных МВЗ
- Используйте контекстное меню для быстрых действий

## Управление центрами затрат (МВЗ)

МВЗ - конкретные подразделения или проекты с собственным бюджетом.

### Создание МВЗ

1. Выберите вкладку "Центры затрат"
2. Нажмите "Добавить МВЗ"
3. Укажите:
   - **Название** - краткое наименование
   - **Финансовый центр** - привязка к ЦФО
   - **Бюджетный лимит** - максимальная сумма (опционально)
   - **Период бюджета** - месячный/квартальный/годовой
4. Подтвердите создание

### Контроль бюджета

- Система отслеживает использование бюджета в реальном времени
- При превышении 80% появляется предупреждение
- При достижении 100% блокируются новые расходы

### Просмотр статистики

- Нажмите на иконку графика для просмотра использования бюджета
- Доступны диаграммы по периодам
- Экспорт отчетов в Excel

## Управление номенклатурами

Номенклатуры - категории доходов и расходов для классификации операций.

### Создание номенклатуры

1. Откройте вкладку "Номенклатуры"
2. Нажмите "Добавить номенклатуру"
3. Заполните:
   - **Название** - наименование категории
   - **Тип** - Доход/Расход
   - **Родительская категория** - для вложенности
   - **Цвет** - для визуального выделения
   - **Иконка** - выберите из библиотеки
4. Сохраните номенклатуру

### Типы номенклатур

- **INCOME** - доходные статьи (зеленый цвет)
- **EXPENSE** - расходные статьи (красный цвет)

### Управление иерархией

- До 5 уровней вложенности
- Автоматическое наследование типа от родителя
- Массовое перемещение подкатегорий

## Управление продуктами

Продукты позволяют вести детализированный учет покупок с отслеживанием цен.

### Добавление продукта

1. Перейдите на вкладку "Продукты"
2. Нажмите "Добавить продукт"
3. Укажите:
   - **Название** - наименование товара
   - **Единица измерения** - кг, л, шт и т.д.
   - **Категория** - привязка к номенклатуре
   - **Начальная цена** - текущая стоимость
4. Сохраните продукт

### История цен

- Автоматическое сохранение изменений цен
- График динамики стоимости
- Расчет средней цены за период

### Связь с номенклатурами

- Продукт может относиться к нескольким категориям
- Используйте мультивыбор для гибкой классификации

## Массовые операции

### Импорт данных

1. Нажмите "Массовые операции"
2. Выберите вкладку "Импорт"
3. Поддерживаемые форматы:
   - **CSV** - текстовый формат с разделителями
   - **Excel** - файлы .xlsx
4. Загрузите файл
5. Сопоставьте колонки
6. Просмотрите и подтвердите импорт

### Шаблоны для импорта

Скачайте шаблоны с правильной структурой:
- Периоды: `period_name, period_year, period_month`
- ЦФО: `financial_center_name, description, parent_name`
- МВЗ: `cost_center_name, financial_center_name, budget_limit`
- Номенклатуры: `nomenclature_name, type, parent_name, color`

### Экспорт данных

1. Откройте "Массовые операции"
2. Перейдите на вкладку "Экспорт"
3. Выберите формат:
   - CSV
   - Excel
   - JSON
4. Настройте параметры:
   - Включить заголовки
   - Только активные записи
   - Диапазон дат
5. Скачайте файл

### Групповые обновления

1. Выберите записи галочками
2. Нажмите "Групповое обновление"
3. Укажите:
   - Поле для изменения
   - Новое значение
   - Условия применения
4. Подтвердите изменения

### Архивирование

1. Откройте "Массовые операции"
2. Вкладка "Архивирование"
3. Установите критерии:
   - Старше N дней
   - Неактивные записи
   - По шаблону
4. Запустите архивацию

## Поиск и фильтрация

### Быстрый поиск

- Используйте поле поиска в панели инструментов
- Поиск по всем текстовым полям
- Результаты появляются мгновенно

### Расширенный поиск

1. Нажмите "Расширенный поиск"
2. Добавьте условия:
   - Выберите поле
   - Оператор сравнения
   - Значение
3. Комбинируйте условия через И/ИЛИ
4. Сохраните фильтр для повторного использования

### Сохраненные фильтры

- Создавайте именованные фильтры
- Делитесь фильтрами с описанием
- Быстрый доступ через выпадающее меню

## История изменений и аудит

### Просмотр истории

1. Нажмите "История и аудит"
2. Фильтры истории:
   - По типу справочника
   - По действию (создание/изменение/удаление)
   - По пользователю
   - По датам

### Детали изменений

- Щелкните на записи для просмотра
- Сравнение версий (diff view)
- Информация об изменившем пользователе

### Восстановление данных

1. Найдите удаленную запись
2. Нажмите "Восстановить"
3. Подтвердите восстановление
4. Запись вернется в активное состояние

### Откат изменений

- Выберите версию для отката
- Просмотрите изменения
- Подтвердите откат
- Создается новая версия с старыми данными

## Горячие клавиши

### Глобальные

- `Ctrl+N` - Создать новую запись
- `Ctrl+S` - Сохранить изменения
- `Ctrl+F` - Фокус на поиск
- `Ctrl+Z` - Отменить последнее действие
- `Ctrl+Y` - Повторить действие
- `F5` - Обновить данные
- `Escape` - Закрыть диалог/отменить

### Навигация по таблице

- `↑/↓` - Перемещение по строкам
- `←/→` - Перемещение по колонкам
- `Space` - Выделить строку
- `Ctrl+A` - Выделить все
- `Enter` - Редактировать
- `Delete` - Удалить выбранные

### Работа с деревом

- `←` - Свернуть узел
- `→` - Развернуть узел
- `Home` - К первому элементу
- `End` - К последнему элементу

## Часто задаваемые вопросы

### Как изменить порядок отображения записей?

Щелкните на заголовок колонки для сортировки. Повторный щелчок изменит направление сортировки.

### Можно ли восстановить случайно удаленные данные?

Да, через раздел "История и аудит" → "Удаленные записи".

### Как перенести данные из другой системы?

Используйте функцию импорта с предварительной подготовкой данных в CSV или Excel формате.

### Почему некоторые записи неактивны?

Записи могут быть деактивированы вручную или автоматически при архивировании. Используйте фильтр "Показать неактивные" для их отображения.

### Как ограничить доступ к определенным справочникам?

Все данные автоматически изолированы по пользователям. Дополнительные ограничения не требуются.

### Можно ли откатить массовые изменения?

Да, каждое изменение записывается в историю. Используйте групповой откат через историю изменений.

### Как экспортировать данные для отчета?

Используйте функцию экспорта с настройкой фильтров и выбором нужного формата.

### Поддерживается ли работа на мобильных устройствах?

Да, интерфейс адаптивен и поддерживает сенсорное управление.
