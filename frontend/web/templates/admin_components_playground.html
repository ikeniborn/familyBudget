FormField - Universal Form Wrapper

Live Example:

Usage:

import { FormField, TextInput } from '@components';

const textInput = new TextInput({
  name: 'username',
  placeholder: 'Enter username'
});

const field = new FormField({
  label: 'Username',
  name: 'username',
  required: true,
  helpText: 'Your unique username',
  children: textInput.render()
});

document.body.appendChild(field.render());

Live Example:

const amountInput = new AmountInput({

}

RecurringPlanSettings - Complex Recurring Config

Features:

  • 3 frequency types: weekly/monthly/yearly
  • MMDD encoding for yearly (e.g., 315 = March 15)
  • Dynamic validation based on type
  • Optional end date

Example Data:

{
  frequencyType: 'monthly',
  frequencyValue: 15,  // 15th of month
  endDate: null        // Indefinite
}

// For yearly:
{
  frequencyType: 'yearly',
  frequencyValue: 315, // March 15
  endDate: '2026-12-31'
}

Form Components (4)

Complete forms with validation and submission

TransactionForm - Full Transaction Form

Used in 8+ places across the application - saves ~400 lines of duplication!

Features:

  • Date input with quick buttons
  • Financial center selection
  • Record type (expense/income)
  • Dynamic article filtering
  • Fact hints (plan/fact for period)
  • Amount validation

Usage:

const form = new TransactionForm({
  container: '#form-container',
  mode: 'create',
  onSubmit: async (data) => {
    const response = await fetch('/api/v1/facts', {
      method: 'POST',
      body: JSON.stringify(data)
    });
    return response.json();
  },
  onSuccess: () => {
    showToast('Saved!');
    modal.close();
  }
});

await form.initialize();

await form.render(container);

Modal Components (3)

Modal management with DaisyUI dialog integration

BaseModal - DaisyUI Dialog Wrapper

Features:

  • DaisyUI dialog integration
  • Automatic ModalKeyboardAdapter integration
  • Backdrop click to close
  • Event callbacks (onOpen, onClose)
  • Dynamic content management

Usage:

const modal = new BaseModal({
  id: 'my-modal',
  title: 'Example Modal',
  content: contentElement,
  onOpen: () => console.log('Opened'),
  onClose: () => console.log('Closed')
});

document.body.appendChild(modal.render());
modal.open();

CrudModal<T> - CRUD Operations Modal

Features:

  • Dynamic mode switching (create/edit)
  • Delete confirmation button
  • Generic form builder pattern
  • API integration helpers
  • Success/Error callbacks

Usage:

const modal = new CrudModal
({
  id: 'article-modal',
  entity: 'article',
  createTitle: 'Create Article',
  editTitle: 'Edit Article',
  formBuilder: (mode, data) => new AdminCrudForm({...}),
  onCreate: async (data) => { /* POST */ },
  onUpdate: async (id, data) => { /* PUT */ },
  onDelete: async (id) => { /* DELETE */ },
  onSuccess: () => reloadTable()
});

// Open for create
modal.openForCreate();

// Open for edit
modal.openForEdit(existingArticle);

Architecture & Design Decisions

Hybrid Architecture (9/10 Score)

Jinja2 server-side templates + TypeScript client-side components

✅ Advantages:

  • Offline-first PWA support
  • HTMX compatibility preserved
  • Type safety (TypeScript)
  • ZERO refactoring of existing widgets
  • Incremental migration path

Component Hierarchy:

Base Components (primitives)
  ↓
Composite Components (business logic)
  ↓
Form Components (complete forms)
  ↓
Modal Components (modal management)

Wrapper Pattern - ZERO Refactoring

Existing widgets remain unchanged, new components wrap them
