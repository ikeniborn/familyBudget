{# PWA Splash Screen Module Controls splash screen visibility for PWA cold starts. Features: - Shows splash only on PWA cold start (app reopened) - Skips splash on F5 reload or in-session navigation - Session-based detection using sessionStorage - Performance API for reload detection - 2 second minimum display time Note: - Splash HTML must be present in base.html before this script - Critical CSS for .pwa-splash must remain inline for instant rendering - Runs as IIFE for immediate execution #}
