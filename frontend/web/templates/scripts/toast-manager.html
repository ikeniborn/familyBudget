{# Toast Manager Module Provides global toast notification functions for base.html. CRITICAL: This module MUST be loaded FIRST before other scripts that use toast notifications. Dependencies: Service Worker, Offline Manager, and other modules rely on showToast() being defined. Functions: - showToast(message, type, duration): Display a simple toast notification - showToastWithAction({message, type, duration, action}): Display toast with action button Types: 'success', 'error', 'warning', 'info' (default) Security: Uses textContent for XSS prevention (not innerHTML). #}
