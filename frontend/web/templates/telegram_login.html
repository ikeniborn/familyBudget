Вход через Telegram

Используйте свой аккаунт Telegram для безопасного доступа к Семейный бюджет. Пароль не требуется!

Почему вход через Telegram?

  • Безопасная аутентификация с валидацией HMAC-SHA256
  • Не нужно запоминать еще один пароль
  • Мгновенный доступ с вашим аккаунтом Telegram
  • Используйте бота (@{{ bot_username }}) для управления бюджетом

Нет Telegram?

Скачайте Telegram с telegram.org и создайте бесплатный аккаунт.
